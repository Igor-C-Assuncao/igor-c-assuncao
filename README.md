## 🏆 Highlighted Projects

---

### 📝 [IA-Notetaker](https://github.com/Igor-C-Assuncao/IA-notetaking)
* **Description:** An intelligent note-taking ecosystem that leverages AI to transform raw thoughts and recordings into structured, actionable knowledge.
* **Key Features:** Automated summarization, semantic search, and context-aware tagging.
* **Stack:** TypeScript, Next.js, OpenAI API, Supabase (Vector Store).

---

### 🚛 [Big Data Pipeline for Vehicle Telemetry (Scania MVP)](https://github.com/Igor-C-Assuncao/mvp-engenharia-dados-scania)
* **Description:** A robust Data Engineering pipeline designed to process and analyze heavy-vehicle telemetry data. Implements the **Medallion Architecture** (Bronze, Silver, Gold) to turn raw sensor data into analytical insights.
* **Techniques:** Dimensional Modeling, Data Governance, Batch Processing, Schema Evolution.
* **Stack:** Databricks, Apache Spark, PySpark, SQL.

---

### 🔧 [Predictive Maintenance with ML](https://github.com/Igor-C-Assuncao/MVP_Manutencao_Preditiva_ML_para_Ativos_Industriais)
* **Description:** Classification models to predict industrial asset failures, optimizing maintenance schedules and reducing operational downtime.
* **Techniques:** EDA, Feature Engineering, Random Forest, XGBoost.
* **Stack:** Python, Pandas, Scikit-learn.

---

### 🎙️ [Industrial Audio Anomaly Detection (MFCC)](https://github.com/Igor-C-Assuncao/Anomaly_Detection_MFCC_TCC)
* **Description:** Research project focused on extracting Mel-Frequency Cepstral Coefficients (MFCCs) to identify mechanical anomalies through acoustic signatures.
* **Techniques:** Digital Signal Processing (DSP), Isolation Forest, One-Class SVM.
* **Stack:** Python, Librosa, Scikit-learn.
